# Lighthouse Accessibility Verification

## How to run

1. Open `index.html` in Chrome.
2. Open DevTools -> **Lighthouse**.
3. Select category: **Accessibility**.
4. Run audit (Desktop or Mobile).

## Pass target

- Accessibility score: **90+**

## Current implementation notes

The app now includes:
- semantic `button` elements (instead of clickable `div`)
- aria labels for interactive controls
- tablist/tab/tabpanel semantics
- keyboard support (Tab/Enter/Space and arrow navigation for tabs)
- visible focus styles
